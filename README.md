# nhaajtt.github.io

Source of https://nhaajtt.github.io, built by GitHub Pages with Jekyll.

## Publish a note

1. Copy `_drafts/template.md` to `_posts/YYYY-MM-DD-title.md`.
2. Fill in the title, tags and text.
3. Commit and push to `master`. The site and the RSS feed update in about a minute.

Only public, sanitized analysis belongs here. Do not publish live malware samples or unreported vulnerabilities.
